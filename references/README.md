# References

Distilled notes and patterns pulled from external n8n-related sources — **not** full clones of external repositories. Each note below records its source so external material is never presented as original work of this lab.

## Categories

- **`n8n-core/`** — node reference, expression syntax, and core n8n behavior, sourced from the official n8n repo.
- **`workflow-patterns/`** — reusable workflow design patterns (error handling, branching, batching, etc.).
- **`ai-agents/`** — patterns for building AI agent workflows in n8n (tool use, structured output, fallback behavior).
- **`mcp/`** — notes on MCP (Model Context Protocol) integration within n8n.
- **`testing/`** — reusable QA/regression checklist templates used across all projects.

## Rules for this folder

1. Never copy entire files or large verbatim blocks from a source repo — distill patterns into original notes.
2. Every subfolder's content that derives from an external source must cite it (link + license).
3. Respect the original repository's license.
4. Keep notes practical — how a pattern applies to workflows built in this lab, not a copy of upstream docs.
