# Projects

Each subfolder here is one self-contained n8n project, named after what it actually does — not a generic placeholder like `project-001/`.

Example:

```text
projects/
└── ai-lead-qualification-agent/
    ├── ai-lead-qualification-agent.json
    ├── README.md
    ├── QA.md
    └── CHANGELOG.md
```

Start new project docs from the templates in [`references/testing/`](../references/testing/): `project-readme-template.md`, `qa-template.md`, `changelog-template.md`.

No project-specific files live outside their own project folder. No projects have been built yet — see [`PROJECT_INDEX.md`](../PROJECT_INDEX.md).
